Engineering validation

  • Exact parity with the original Python XGBoost: max |Δp| = 6.6×10⁻⁷ across 69 reference wafers.
  • Exact TreeSHAP equals pred_contribs to 1.3×10⁻⁶ (efficiency axiom verified).
  • 0.05 ms per inference · 0.6 ms per explanation (Node 22, single core).
  • Zero cold start: static assets + in‑browser inference. Nothing to wake up.

Scope & limitations

        
    
          
  • Trained on simulated wafers (≈5,400 samples, 600/class); results are a proof of concept, not production‑validated.
    • 
          
  • Training features occupy narrow bands (see slider shading). Inputs far outside them are flagged as out‑of‑distribution.
    • 
          
  • The wafer map is a schematic reconstruction from summary statistics, not an inspection image.
    • 
          
  • Counterfactuals describe the model's decision surface, not physical causality.
